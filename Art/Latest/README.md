# Art/Latest

Blenderの**最新の原本のみ**を置くディレクトリ。ここに入ったファイルだけがGit LFSで追跡される。

## 運用

- 工程フォルダ（`ElseIf_Blockout_20260922/<工程名>_<日付>/`）は作業場所であり、Gitには入らない
  - スクリプトが絶対パスで参照しているため、工程フォルダのファイルは移動・改名しないこと
- 工程が一区切りついたら、その成果物を `Art/Latest/` に**コピー**して同名で上書きする
- `.gitignore` は `!Art/Latest/*.blend` でこのディレクトリを例外扱いしている。
  ファイル名を変えても追跡対象のままなので、ignoreの書き換えは不要

## LFS容量について

GitHubのLFS無料枠はストレージ1GB・帯域1GB/月。
ここに大量の世代を置くと枠を使い切るため、**原則1本だけ**を維持する。
過去世代を残したい場合はGit外のバックアップか、データパック購入を検討すること。
