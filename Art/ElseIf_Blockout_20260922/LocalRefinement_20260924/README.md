## 実測と編集
人体および衣装をBlender MCP経由で読み取りました。基準姿勢の左肩関節は (0.08915, 0.02525, 1.35649)m、肩先の人体表面は (0.12626, 0.02525, 1.35500)m、肩関節上方の表面は高さ1.36317m、脇下面のサンプルは (0.10500, 0.02525, 1.24356)mです。鎖骨前面と上腕表面も測定しています。詳細は01_inspect.jsonと02_anatomy_topology.jsonを参照してください。
既存の袖付け境界に沿って弱い谷と立ち上がりを作り、肩先からの落ち方と脇の二つの広い面を整理しました。初期補正は最大約3.14mmで、人体との距離が小さい支持部ではさらに減衰させています。袖丈、肘・手首周辺の既存変形、胴幅、裾には変更を加えていません。
靴はつま先側の幅と丸み、弱いつま先の反り、甲の移行、前側がわずかに下がる履き口を整理しました。既存の白い締結帯を曲面へ追従させ、タンとつま先、ソール底部を既存材質で区別しています。ソールを厚くしたり靴全体を拡大したりしていません。靴の頂点変位は最大約7.2mmです。
